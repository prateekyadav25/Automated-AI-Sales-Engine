# API Architecture

Prefix: `/api/v1`.

Envelope:

```json
{ "data": {}, "meta": { "page": 1, "page_size": 25, "total": 0 }, "error": null }
```

## Errors

`401` unauthenticated, `403` forbidden, `404` not found, `409` conflict, `422` validation. Every response includes `X-Correlation-ID`.

## MVP endpoints

- `GET /health` `GET /ready`
- Auth: `POST /auth/login` `POST /auth/refresh` `POST /auth/logout` `GET /auth/me`
- Admin: users, roles, teams, territories, flags, audit
- CRM: accounts, contacts, leads, opportunities, tasks, activities
- `POST /leads/{id}/score`
- `POST /opportunities/{id}/close-won`
- Command center: `GET /command-center/kpis`
- AI: `POST /ai/copilot/chat` `POST /ai/research/accounts/{id}` `POST /ai/summaries/{entity}` `POST /ai/drafts/email`
- Knowledge: upload, list, search
- Approvals: list, approve, reject
- NBA: list / generate for an entity

OpenAPI is generated by FastAPI. TypeScript types are copied into `packages/types` as the contract evolves.
