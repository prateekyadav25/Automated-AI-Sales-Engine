# Observability

- Structured JSON logs with correlation_id and tenant_id
- OpenTelemetry traces on API, worker, and agent runs
- Prometheus `/metrics`
- Grafana-compatible dashboards later

Monitor API latency, DB, Redis, jobs, integrations, agents, LLM cost, email/voice, webhooks.

AI observability fields: provider, model, agent, prompt version, latency, tokens, cost, tools, success, approval, human feedback.
